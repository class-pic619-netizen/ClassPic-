# ClassPic UI — แนวทางออกแบบ (ฉบับ 2026-11-08)

> ฉบับก่อนหน้าสั่งให้ใช้กรอบกรมท่าหนา เงาทึบเยื้อง (`shadow-[4px_4px_0px_...]`) ป้ายภาษาอังกฤษตัวพิมพ์ดีด
> (`FOLIO #01`, `STUDIO PROOF BOARD`, `INDEX 01`) และพื้นตาราง ซึ่งกลายเป็น "หน้าตา AI" อีกแบบหนึ่ง
> ผู้ใช้ไม่ชอบ จึงยกเลิกทั้งหมด ห้ามนำกลับมาใช้

ต้นแบบที่ผู้ใช้อนุมัติ: `docs/mockups/home-v2.html` และหน้าเว็บจริงใน `src/app/page.tsx`

## 1. หลักใหญ่
1. **ใบงานคือพระเอก** — สิ่งที่ครูอยากเห็นคือเนื้อหาใบงาน ไม่ใช่ลูกเล่นหน้าเว็บ
   ใช้ `WorksheetPaperPreview` (หรือรูปสแกนจริงใน `cover_image` ที่ขึ้นต้นด้วย `/`) ทุกที่ที่โชว์สินค้า
   ห้ามใช้รูปสต็อก (Unsplash ฯลฯ) แทนใบงาน
2. **พื้นที่ว่างมาก่อน กรอบมาทีหลัง** — พื้นขาว เส้นแบ่งบาง `border-line` ใช้กล่อง (`panel`) เฉพาะฟอร์มหรือสรุปยอด
3. **สีส้มสำหรับปุ่มซื้อเท่านั้น** (`btn-primary`) ปุ่มอื่นใช้ `btn-secondary` หรือข้อความลิงก์สีฟ้า
4. **เขียนแบบที่ครูพูด** — สั้น ตรง บอก ชั้น / วิชา / จำนวนหน้า / มีเฉลยไหม / ราคา
   ห้ามอธิบายสโลแกนแบรนด์ให้ลูกค้าฟัง ห้ามศัพท์ประดิษฐ์ เช่น "แฟ้มสั่งซื้อ" "เปิดแฟ้มใบงาน" "สตูดิโอใบงาน"
5. **โลโก้อยู่ที่เมนูกับท้ายเว็บเท่านั้น** (`/logo-wordmark.png`) ไม่ต้องวางซ้ำในหน้าแรกหรือในใบงาน

## 2. ห้ามทำ
- กรอบหนา `border-2 border-[#142E4F]` และเงาทึบเยื้องทุกแบบ
- ป้ายภาษาอังกฤษตัวพิมพ์ใหญ่/`font-mono` เพื่อความ "เท่" (`SPEC`, `EDITION`, `READY TO PRINT`, `[X]`)
- Emoji ในปุ่ม ป้าย หัวข้อ หรือชื่อสินค้า
- ป้ายแคปซูลมีจุดเรืองแสงเหนือหัวข้อ, แถว ✓ สามอันใต้ปุ่ม, ไล่สี gradient บนแบนเนอร์
- ไอคอน `Sparkles`, `ShieldCheck`, `Zap`, `Rocket` และไอคอนประดับที่ไม่ได้ช่วยให้เข้าใจ
- ลายน้ำหลายแถวที่บังเนื้อหา — ใช้ `WatermarkOverlay` คำเดียวจาง ๆ (กฎ AGENTS.md ยังบังคับให้มีลายน้ำ)

## 3. ระบบที่มีให้ใช้ (`src/app/globals.css`)
| ใช้ทำอะไร | คลาส / ค่า |
|---|---|
| สีแบรนด์ | `cp-navy #142E4F`, `cp-blue #2856B0`, `cp-sky #AED6F4`, `cp-orange #F26C28` |
| พื้นหลังอ่อน | `bg-cp-bg` (เทาฟ้า), `bg-cp-mist` (ฟ้าอ่อน) |
| ตัวอักษร | `text-ink` (เนื้อหา), `text-muted` (รอง), เส้น `border-line` |
| ฟอนต์หัวข้อ | `font-head` = Nunito (ละติน/ตัวเลข) + Mitr (ไทย) — `h1–h4`, `button` ใช้อัตโนมัติ |
| ฟอนต์เนื้อหา | Anuphan (ค่าเริ่มต้นของ `body`) |
| ปุ่ม | `btn-primary`, `btn-secondary` |
| กล่อง / ช่องกรอก | `panel`, `input-field` |
| กระดาษใบงาน | `paper` (เงานุ่ม มุมคม) + สัดส่วน `aspect-[210/297]` |
| ไอคอน | `/public/icons/*.svg` (Streamline Flex ระบายสีแบรนด์แล้ว ต้องคงเครดิต Streamline ใน Footer) |

ความกว้างหน้า: `max-w-6xl mx-auto px-5 sm:px-7` (หน้าฟอร์ม/รายการใช้ `max-w-3xl`–`max-w-5xl`)

## 3.1 ข้อยกเว้น: หลังบ้าน `/admin` (ผู้ใช้สั่งเอง 2026-11-10)
หลังบ้านเป็นแดชบอร์ดธีมมืดกรมท่าตามภาพตัวอย่างที่ผู้ใช้ส่งมา — ใช้แสงเรือง กระจก และ gradient ได้ **เฉพาะใน `/admin`**
- ใช้คลาส `.admin-dark` (กรอบนอก) และ `.cp-glass` (การ์ด) ใน `globals.css`; สียังต้องอยู่ในชุดแบรนด์ (กรมท่า/ฟ้า/ฟ้าอ่อน/ส้ม) + เขียวมิ้นต์ `#7FD1C7` สำหรับตัวเลขดี
- ห้ามนำสไตล์นี้ไปใช้กับหน้าร้านที่ลูกค้าเห็น
