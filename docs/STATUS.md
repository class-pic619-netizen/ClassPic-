    - สร้าง API `POST /api/verify-slip` ตรวจสลิป 4 ด่าน รองรับทั้ง Multipart Form และ Base64, ใช้ `sharp` + `jsqr` ถอดรหัส Mini QR ธนาคาร, ตรวจจับและสกัด TransRef, บล็อกสลิปซ้ำ 100%, พร้อมโหมดคู่ (โหมดฟรี ฿0 พร้อมส่ง Telegram Notify และโหมด API ต่อ EasySlip)
    - สร้าง `src/lib/pdfSecurity.ts` รองรับการออก Signed URL (HMAC-SHA256 Token อายุ 15 นาทีตามสเปก) และเอ็นจิ้นสร้างไฟล์มาสเตอร์ PDF ขนาดกระดาษ A4 มาตรฐานไทย (210 x 297 mm) ความละเอียดคมชัดสูง 300 DPI พร้อมลายน้ำลิขสิทธิ์เฉพาะผู้สั่งซื้อและหน้าเฉลย
    - สร้าง API `GET /api/download/[orderId]/[productId]` ตรวจสอบสิทธิ์การซื้อ ตรวจสอบอายุของลิงก์ลับ 15 นาที และสตรีมส่งมอบไฟล์ PDF ขนาด A4 ที่ปริ้นท์ได้จริง
    - สร้างหน้า `/downloads` ค้นหาประวัติใบงานที่เคยซื้อด้วยเบอร์โทร/อีเมล พร้อมชิปทดลองค้นหา (`081-234-5678`)
    - สร้างหน้า `/downloads/[orderId]` แสดงรายการใบงานที่สั่งซื้อ พร้อมปุ่มดาวน์โหลด PDF A4 คมชัดสูง ปุ่มคัดลอกลิงก์ 15 นาที และวิดเจ็ตแนบสลิปเพื่อปลดล็อกทันทีหากยังค้างชำระ
    - ผ่านการทดสอบ Build (`npm run build`) ใน Next.js 16 สำเร็จ 100% (24/24 static & dynamic routes) ไม่มี Error ใดๆ
