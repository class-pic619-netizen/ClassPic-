## 4. มาตรการความปลอดภัยและมาตรฐานทางเทคนิคที่ล็อกไว้แล้ว

1. **การป้องกันการขโมยไฟล์ PDF:**
   - ห้ามนำไฟล์ PDF ตัวจริงไปไว้ในโฟลเดอร์สาธารณะ (`public/`) เด็ดขาด
   - ไฟล์จะถูกจ่ายผ่าน **Signed URL (HMAC-SHA256 Token) ที่มีอายุจำกัดเพียง 15 นาที** เท่านั้น
   - รูปตัวอย่างทุกหน้าบนเว็บไซต์จะถูกซ้อนทับด้วยคอมโพเนนต์ `WatermarkOverlay` คาดลายน้ำ `ClassPic Studio` อัตโนมัติ
2. **ระบบตรวจสลิป 4 ด่าน ป้องกันสลิปปลอมและสลิปซ้ำ:**
   - **ด่าน 1:** สแกนหา Mini QR Code ธนาคารบนสลิปโอนเงิน
   - **ด่าน 2:** เช็กหมายเลขรหัสธุรกรรม `TransRef` กับตาราง `verified_slips` หากเคยใช้แล้วจะปฏิเสธทันที
   - **ด่าน 3 & 4 (โหมดคู่):**
     - *โหมดฟรี ฿0:* บันทึกสลิปและส่งแจ้งเตือน Telegram / หน้าแอดมิน เพื่อกดอนุมัติใน 1 คลิก
     - *โหมดอัตโนมัติ 24 ชม.:* ยิงเช็กกับ EasySlip API เมื่อมี API Key
3. **ความเข้ากันได้ของระบบชำระเงิน:**
   - สร้าง QR Code พร้อมเพย์ตามมาตรฐาน EMVCo ของธนาคารไทยแท้ พร้อมฟังก์ชันบันทึกภาพลงเครื่องเพื่อเปิดสแกนในแอปธนาคารบนมือถือได้ทันที

## 5. วิธีการนำโปรเจกต์นี้ไปเปิดใช้งานหรือย้ายที่ (Separation / Deployment Guide)

เมื่อคุณต้องการนำโฟลเดอร์นี้ไปสร้างเป็น Git Repository ใหม่ หรือย้ายไปทำงานในบัญชีอื่น:

### ขั้นตอนที่ 1: ตรวจสอบความเรียบร้อยของโค้ด
```bash
npm run build
```
*(สถานะปัจจุบัน: ผ่านสมบูรณ์ 100% ทั้ง 24 routes ไม่มี TypeScript หรือ Lint Error)*

### ขั้นตอนที่ 2: ตั้งค่า Remote ไปยัง GitHub ใหม่ (เมื่อคุณพร้อมสั่งการ)
```bash
# ตัวอย่าง: สร้าง Repo ส่วนตัวใหม่บน GitHub และ Push ขึ้นไป
gh repo create ClassPic-Store --private --source=. --remote=origin --push
```

### ขั้นตอนที่ 3: การรันในเครื่องสำหรับพัฒนา (Local Dev)
```bash
npm install
npm run dev
# เปิดเบราว์เซอร์ไปที่: http://localhost:3000
```

### ขั้นตอนที่ 4: การนำขึ้นออนไลน์บน Vercel (ฟรี ฿0)
1. ไปที่ [vercel.com](https://vercel.com) ล็อกอินด้วยบัญชี GitHub
2. กด **Add New Project** แล้วเลือก Repo `ClassPic-Store`
3. กำหนดค่าใน **Environment Variables** ตามตัวอย่างใน `.env.example`
4. กด **Deploy** เว็บไซต์จะออนไลน์ทันทีภายใน 1-2 นาที
