# โฟลเดอร์คลังใบงานต้นฉบับ (Worksheet Assets)

โฟลเดอร์นี้ใช้จัดเก็บไฟล์ใบงานต้นฉบับจริงใน Repo แยกเป็นรายชุดอย่างเป็นระเบียบ:

## โครงสร้างในแต่ละชุด:
```text
content/worksheets/
├── WS-001-english-vocab-p1/
│   ├── info.json          # ข้อมูลชื่อชุด, ราคา, ระดับชั้น, วิชา, คำอธิบาย
│   ├── cover.jpg          # รูปหน้าปก
│   ├── previews/          # รูปตัวอย่างสลับหน้า (จะถูกนำไปคาดลายน้ำ)
│   └── master.pdf         # ไฟล์ PDF ขนาด A4 คมชัดสูง 300 DPI
└── ...
```

> ⚠️ **คำเตือนด้านความปลอดภัย:**
> ไฟล์ `master.pdf` ในระบบจริงจะถูกซิงก์ขึ้น Supabase Storage ในถังลับ `private-pdfs` 
> และไม่อนุญาตให้ผู้ใช้เข้าถึงผ่าน URL ตรงๆ แต่จะต้องผ่านระบบความปลอดภัย **Signed URL ที่มีอายุ 15 นาที** เสมอ
