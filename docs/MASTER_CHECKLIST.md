## รายละเอียดสิ่งที่ต้องทำรายโมดูล (Detailed Tasks)

### โมดูล M0: การเตรียมพิมพ์เขียวและโครงสร้างเอกสารตั้งต้น
- [x] **M0.1** กำหนดชื่อแบรนด์ใหม่ **ClassPic (Learning & Creative Studio)** และชุดสีมาตรฐาน 4 สี
- [x] **M0.2** ออกแบบพิมพ์เขียวสถาปัตยกรรมระบบ จุดเชื่อมต่อ และโครงสร้างฐานข้อมูล (`docs/BLUEPRINT.md`)
- [x] **M0.3** สร้างระบบเอกสารบังคับบันทึกความคืบหน้า (`AGENTS.md`, `docs/MASTER_CHECKLIST.md`, `docs/STATUS.md`)

---

### โมดูล M1: การตั้งค่าโปรเจกต์ Next.js + ชุดสี/โลโก้แบรนด์ ClassPic
- [x] **M1.1** สร้างโปรเจกต์ Next.js (App Router + TypeScript + Tailwind CSS)
- [x] **M1.2** ตัดแยกไฟล์โลโก้ `ClassPic` (แนวนอน) และไอคอนตัว `C` (Favicon / App Icon) จาก `assets/classpic-brand-sheet.jpg`
- [x] **M1.3** ตั้งค่าตัวแปรสี (`--cp-navy`, `--cp-blue`, `--cp-sky`, `--cp-orange`) และฟอนต์ภาษาไทยอ่านง่าย
- [x] **M1.4** สร้างแถบเมนูบน (Navbar) และส่วนท้ายเว็บ (Footer) ตามภาพร่างในพิมพ์เขียว
- [x] **M1.5** สร้างข้อมูลใบงานจำลอง (Mock Data 3–4 ชุด) เพื่อให้ทดสอบระบบได้ทันทีก่อนใบงานจริงทยอยตามมา

---

### โมดูล M2: หน้าบ้าน (แคตตาล็อกใบงาน + ตัวกรอง + หน้าดูตัวอย่างติดลายน้ำ)
- [x] **M2.1** สร้างหน้าแรก (`/`) พร้อมแบนเนอร์ ClassPic และปุ่มดาวน์โหลดใบงานตัวอย่างฟรี
- [x] **M2.2** สร้างปุ่มกรองหมวดหมู่ตามระดับชั้น (`อนุบาล`, `ป.1-ป.3`, `ป.4-ป.6`, `การศึกษาพิเศษ`, `2 ภาษา`) และช่องค้นหา
- [x] **M2.3** สร้างการ์ดแสดงใบงาน (รองรับทั้งสถานะ `เปิดขายจริง` และ `เร็วๆ นี้ / Coming Soon`)
- [x] **M2.4** สร้างหน้ารายละเอียดใบงาน (`/products/[slug]`) พร้อมตัวเลื่อนดูรูปตัวอย่างขนาด A4 ที่คาดลายน้ำ `ClassPic Studio` อัตโนมัติ

---

### โมดูล M3: ระบบตะกร้าสินค้า + สร้าง QR PromptPay ล็อกยอดเงินอัตโนมัติ
- [x] **M3.1** สร้างระบบตะกร้าสินค้า (เพิ่ม/ลบใบงาน คำนวณราคารวม เก็บสถานะในเครื่องลูกค้าไม่หายเมื่อรีเฟรช พร้อมหน้า `/cart` แบบเต็ม)
- [x] **M3.2** สร้างหน้าชำระเงิน (`/checkout`) ให้กรอกแค่เบอร์โทรศัพท์หรืออีเมล (ไม่ต้องสมัครสมาชิกซับซ้อน) พร้อมขั้นตอนสแกนและแนบสลิป
- [x] **M3.3** สร้างจุดเชื่อม `POST /api/promptpay` เจนรูป QR Code พร้อมเพย์มาตรฐานธนาคารไทยที่ล็อกยอดเงินตรงตามราคาใบงานอัตโนมัติ (และ `POST /api/orders` สำหรับสร้างคำสั่งซื้อ)

---

### โมดูล M4: ระบบตรวจสลิป 4 ด่าน (ป้องกันสลิปปลอม & สลิปซ้ำ)
- [x] **M4.1** สร้างระบบสแกนอ่าน Mini QR Code จากรูปสลิปที่ลูกค้าแนบมา (ใช้ `sharp` + `jsqr` ถอดรหัสรูปภาพทุกฟอร์แมต)
- [x] **M4.2** สร้างด่านเช็กรหัสธุรกรรม `TransRef` กับฐานข้อมูล เพื่อบล็อกสลิปที่เคยถูกใช้ซื้อไปแล้ว 100%
- [x] **M4.3** สร้างโหมดตรวจยอดเงินที่ 1 (โหมดฟรี ฿0): บันทึกสลิป ตรวจสอบ TransRef/Image Hash ปรับเป็น PAID และแจ้งเตือน Telegram Bot พร้อมเพย์โหลด
- [x] **M4.4** สร้างโหมดตรวจยอดเงินที่ 2 (โหมดอัตโนมัติ 24 ชม.): เชื่อมต่อ API เช็กสลิปธนาคาร (EasySlip) เพียงใส่ `EASYSLIP_API_KEY` ใน Environment ก็เปิดใช้งานอัตโนมัติได้ทันที

---

### โมดูล M5: ระบบรับไฟล์ PDF ลิงก์ลับ + หน้าค้นหาใบงานที่เคยซื้อ
- [x] **M5.1** สร้างหน้าดาวน์โหลดไฟล์ (`/downloads/[orderId]`) ที่ปลดล็อกปุ่มดาวน์โหลดทันทีเมื่อสถานะออเดอร์เป็น `PAID` พร้อมวิดเจ็ตแนบสลิปในหน้ากรณีรอชำระ
- [x] **M5.2** สร้างจุดเชื่อม `GET /api/download/[orderId]/[productId]` เพื่อจ่ายลิงก์ดาวน์โหลดชั่วคราว (Signed URL อายุ 15 นาที พร้อม HMAC Verification) และสตรีมไฟล์ PDF ขนาด A4 300 DPI คุณภาพสูง
- [x] **M5.3** สร้างระบบค้นหาใบงานย้อนหลังด้วยเบอร์โทรศัพท์/อีเมล (`/downloads`) พร้อมชิปทดลองค้นหา เพื่อให้ลูกค้ากลับมาโหลดไฟล์ซ้ำได้ตลอดชีพ

---

### โมดูล M6: หน้าหลังบ้าน `/admin` & เชื่อมต่อฐานข้อมูลจริงขึ้นออนไลน์
- [x] **M6.1** สร้างหน้า `/admin` (ป้องกันด้วยรหัสผ่านความปลอดภัยแอดมิน)
- [x] **M6.2** สร้างฟอร์ม **"เพิ่มใบงานใหม่"** บนหน้า `/admin` (อัปโหลด/ใส่รูปตัวอย่าง สเปก A4 ตั้งราคา และสวิตช์ Coming Soon) ให้ทยอยลงใบงานเพิ่มได้ตลอดเวลาโดยไม่ต้องแก้โค้ด
- [x] **M6.3** สร้างตารางจัดการออเดอร์ ดูรูปสลิปขยายใหญ่ และปุ่มกดอนุมัติ `[✅ อนุมัติ 1 คลิก]` และปฏิเสธในหน้า `/admin`
- [x] **M6.4** เตรียมสคริปต์ SQL (`supabase/schema.sql`) สำหรับ 4 ตาราง + Storage 3 Buckets พร้อมไฟล์ `.env.example` และ `supabaseClient.ts` รองรับการ Deploy ขึ้น Vercel ได้ทันที
