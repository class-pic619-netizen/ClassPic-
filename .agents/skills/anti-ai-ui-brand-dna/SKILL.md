# Anti-AI UI & Brand DNA Design System Skill

สกิลนี้มีไว้เพื่อ **ทำลายแพตเทิร์นหน้าเว็บสำเร็จรูปที่ดูออกทันทีว่า AI เขียน (AI Slop / Generic Tailwind Template)** และบังคับใช้สถาปัตยกรรมการออกแบบระดับ **Creative Studio / Editorial Brand** ที่มี DNA ของแบรนด์อยู่ในทุกพิกเซล

---

## 1. บัญชีดำ: สิ่งที่ "ห้ามทำเด็ดขาด" เพราะฟ้องว่าเป็นเว็บ AI (The AI-Slop Ban List)

เมื่อเขียนหรือแก้ไขโค้ด UI ห้ามใช้แพตเทิร์นเหล่านี้โดยเด็ดขาด หากพบในโค้ดเดิมต้องรื้อออกทันที:

1. **❌ ห้ามใส่ Emoji ในปุ่ม แถบตัวกรอง หรือหัวข้อ (`✨`, `🚀`, `🎒`, `✏️`, `🌟`, `🌏`, `🔥`)**
   - *เหตุผล:* เว็บที่ AI เจนเกือบ 100% ชอบเอา Emoji มาแปะหน้าคำในปุ่ม Filter
   - *สิ่งที่ต้องทำแทน:* ใช้รหัสหมวดหมู่แบบแคตตาล็อกสิ่งพิมพ์ (`01`, `02`, `K-3`, `P.1–3`), จุดสีตามระบบแบรนด์ หรือเส้นขีดใต้แบบ Editorial
2. **❌ ห้ามทำป้ายแคปซูลจุดไฟเรืองแสงเหนือหัวข้อ Hero (`<span class="rounded-full"><span class="w-2 h-2 rounded-full"></span> ชื่อแบรนด์</span>`)**
   - *เหตุผล:* นี่คือลายเซ็นอันดับ 1 ของ Landing Page ที่สร้างโดย AI SaaS Template
   - *สิ่งที่ต้องทำแทน:* ใช้เส้นคั่นแนวนอนขนาบข้างข้อความ (`——— LEARNING & CREATIVE STUDIO ———`) ตามโครงสร้างโลโก้จริงของแบรนด์ หรือใช้หัวกระดาษแบบนิตยสาร/สตูดิโอ
3. **❌ ห้ามเรียง Checkmark 3 อันใต้ปุ่มกด (`✓ ฟีเจอร์ 1  ✓ ฟีเจอร์ 2  ✓ ฟีเจอร์ 3`)**
   - *เหตุผล:* เป็นบล็อกสำเร็จรูปที่ AI ชอบใส่ปิดท้าย Hero ทุกเว็บ
   - *สิ่งที่ต้องทำแทน:* ทำเป็น **Spec Strip (แถบสเปกงานพิมพ์จริง)** เช่น ตารางเส้นบางระบุ `FORMAT: A4 (210×297 MM)` | `RESOLUTION: 300 DPI VECTOR PDF` | `DELIVERY: INSTANT PROMPTPAY QR`
4. **❌ ห้ามใช้ Lucide Icons โหลๆ พร่ำเพรื่อ (`Sparkles`, `ShieldCheck`, `Zap`, `Rocket`)**
   - *เหตุผล:* ไอคอน `Sparkles` คือสัญลักษณ์ของ AI
   - *สิ่งที่ต้องทำแทน:* วาด **Custom Brand SVG Motif** จากโลโก้ของแบรนด์โดยตรง (เช่น สำหรับ ClassPic คือ **สามเหลี่ยม Play มุมมนสีส้ม + รัศมีประกาย 3 ขีด**)
5. **❌ ห้ามใช้กล่องโค้งมนเงาฟุ้งแบบเดียวกันทั้งหน้า (`rounded-xl shadow-md` ซ้ำๆ ทุกจุด)**
   - *เหตุผล:* ทำให้เว็บแบน ไม่มีมิติของวัสดุจริง
   - *สิ่งที่ต้องทำแทน:* แยกวัสดุให้ชัด — **"แผ่นกระดาษใบงาน"** ต้องมีสัดส่วน A4 จริง มุมคมกริบ (`rounded-[3px]`) พร้อมเงาชั้นกระดาษซ้อน (`shadow-[4px_4px_0px_#082340]` หรือ `shadow-[6px_6px_0px_#B5D5F2]`) ส่วน **"ปุ่มกดและป้ายสตูดิโอ"** มีเส้นขอบชัด (`border-2 border-[#082340]`) และเอฟเฟกต์กดยุบตามแรงนิ้ว (`active:translate-y-0.5`)

## 2. การถอดรหัส DNA แบรนด์ "ClassPic" (*Bright Outside — Clear Inside*)

เมื่อออกแบบสำหรับแบรนด์ **ClassPic — Learning & Creative Studio** ต้องยึดโครงสร้างจากแผ่น Brand Sheet ต้นฉบับ 100%:

### 2.1 โครงสร้างโลโก้และตัวอักษรแบรนด์ (`ClassPicWordmark`)
- ห้ามพิมพ์คำว่า `ClassPic` ด้วยสีเดียวเรียบๆ เด็ดขาด!
- ต้องเรนเดอร์ด้วยสัดส่วนต้นฉบับเสมอ:
  - **`Cla`** = สีกรมท่าเข้ม `#082340` (Font ExtraBold / Rounded Geometric)
  - **`ss`** = สีส้มสด `#F5760A` (หัวใจของความสดใส — *Bright Outside*)
  - **`Pic`** = สีกรมท่าเข้ม `#082340` โดยที่ **จุดบนตัว `i` ต้องแทนที่ด้วย SVG รูปสามเหลี่ยม Play สีส้ม (`#F5760A`) และขีดรัศมี 3 เส้น** เสมอ!
- บรรทัดรองใต้โลโก้: เส้นตรงสีฟ้า `#1C64B8` ขนาบซ้าย-ขวาของคำว่า `LEARNING & CREATIVE STUDIO` (เว้นระยะตัวอักษร `tracking-[0.22em]`)
- บรรทัดสโลแกน: `Bright Outside — Clear Inside` ใช้ตัวเอียง (`italic`) สีกรมท่า `#082340`

### 2.2 ปรัชญาการใช้สีตามสโลแกน "Bright Outside — Clear Inside"
- **Bright Outside (ภายนอกสว่าง โปร่ง สดใส น่าหยิบจับ):**
  - พื้นหลังหน้าเว็บและแถบ Header ด้านบนต้อง **สว่างเหมือนกระดาษสตูดิโอ (`#FAFBFD` / `#FFFFFF`)** ขับให้โลโก้ `ClassPic` (กรมท่า-ส้ม) โดดเด่นออกมาเหมือนป้ายสตูดิโอเครื่องเขียนญี่ปุ่น/สแกนดิเนเวีย (ไม่ถมแถบ Header เป็นสีมืดทึบแบบเว็บองค์กรเก่าๆ)
  - ใช้สีส้ม `#F5760A` และสีฟ้าอ่อน `#B5D5F2` เป็นจุดดึงสายตาและพื้นหลังโซนไฮไลต์
- **Clear Inside (ภายในชัดเจน เป็นระบบ โครงสร้างเป๊ะ):**
  - ใช้เส้นตารางและกรอบสีกรมท่า `#082340` (`border-[#082340]`) จัดระเบียบข้อมูลใบงานให้เหมือน **แฟ้มสะสมงาน (Archival Binder / Print Catalog)** ที่ครูมองปุ๊บรู้ทันทีว่า ชั้นไหน กี่หน้า ราคาเท่าไหร่

## 3. เทคนิคการจัดวางหน้าจอให้เหมือนดีไซเนอร์ออกแบบเอง (Studio UI Craft)

1. **Studio Header & Ribbon:**
   - แถบบนสุดเป็นแถบประกาศสั้นๆ สีกรมท่า `#082340` สูงเพียง 32px แจ้งมาตรฐานงานพิมพ์ (`A4 THAI STANDARD • 300 DPI PRINT-READY PDF • INSTANT PROMPTPAY DELIVERY`)
   - ตัว Navbar หลักเป็นพื้นขาวสะอาด (`bg-white/95 backdrop-blur`) เส้นขอบล่างสีกรมท่า `#082340` โชว์โลโก้ `ClassPic` ที่มี `ss` สีส้มและประกายไฟบนตัว `i` อย่างสง่างาม
2. **Editorial Desk Hero (โต๊ะจัดแสดงใบงานจริง ไม่ใช่แบนเนอร์โฆษณา AI):**
   - แบ่งโครงสร้างแบบนิตยสาร/สตูดิโอดีไซน์: ฝั่งซ้ายสื่อสารตัวตนแบรนด์ด้วย Typography ที่มีจังหวะหนัก-เบา + ปุ่มกดสไตล์ Tactile Studio (`border-2 border-[#082340] shadow-[4px_4px_0px_#082340]`)
   - ฝั่งขวาจัดวาง **"แผ่นใบงาน A4 บนโต๊ะสตูดิโอ"** มีคลิปหนีบกระดาษ/ป้ายสเปก (`SHEET 01 / 25 • 210×297 MM`) และปุ่มกดพลิกดูหน้าใบงานตัวอย่างได้จริงตั้งแต่หน้าแรก!
3. **Binder-Tab Filter System (ตัวกรองแบบแถบแฟ้มเอกสาร ไม่ใช่ปุ่ม Emoji):**
   - ออกแบบปุ่มเลือกชั้นเรียนให้เหมือน **ป้ายคั่นแฟ้ม (Index Tabs)** ที่มีหมายเลขหมวดหมู่กำกับ (`ALL`, `01 อนุบาล`, `02 ป.1–ป.3`, `03 ป.4–ป.6`, `04 การศึกษาพิเศษ`, `05 2 ภาษา`)
4. **Tactile Worksheet Card (การ์ดใบงานที่มีมิติเหมือนซองใส่ชีตเรียน):**
   - ตัวการ์ดมีแถบหัวแฟ้มระบุรหัสชุดใบงาน (`CP-01`, `A4 • 25 PGS`)
   - รูปใบงานด้านในตั้งอยู่บนพื้นสีฟ้าอ่อน `#B5D5F2/35` เหมือนวางอยู่บนแผ่นรองตัด เมื่อเอาเมาส์ชี้ แผ่นกระดาษจะขยับยกตัวขึ้นเล็กน้อย
   - ป้ายราคาและปุ่มสั่งซื้อแยกส่วนชัดเจนด้วยเส้นตารางแบบใบเสร็จ/แคตตาล็อกงานพิมพ์

## 4. ขั้นตอนการตรวจสอบหลังแก้ UI (Self-Verification Checklist)

ก่อนส่งมอบงาน UI ทุกครั้ง ต้องตรวจเช็ก 5 ข้อนี้ให้ผ่านครบ 100%:
- [ ] ไม่มี Emoji ปะปนในปุ่มตัวกรองหรือป้ายสถานะแล้วใช่หรือไม่?
- [ ] โลโก้ `ClassPic` แสดงสี `Cla` (กรมท่า) + `ss` (ส้ม) + `Pic` (กรมท่าพร้อมประกายสามเหลี่ยมสีส้มบนตัว `i`) ตรงตามรูปต้นฉบับแล้วใช่หรือไม่?
- [ ] หน้าเว็บให้ความรู้สึกสว่าง คมชัด เหมือนสตูดิโอขายสื่อการสอน (`Bright Outside — Clear Inside`) แทนที่จะเป็นเว็บมืดๆ ทึบๆ แบบเทมเพลต AI แล้วใช่หรือไม่?
- [ ] การ์ดใบงานแสดงสัดส่วนกระดาษ A4 จริง และมีรายละเอียดสเปกงานพิมพ์ชัดเจนหรือไม่?
- [ ] รัน `npm run build` ผ่าน 100% โดยไม่มี TypeScript หรือ CSS Error ใช่หรือไม่?
